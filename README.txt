ZEN DOTS PREMIUM EDITION v3

Güncelleme paketi. Mevcut Netlify sitenizin yerine bu klasörün içeriğini yayınlayın:
- index.html
- manifest.webmanifest
- sw.js
- icons/

Netlify mobil güncelleme:
1. ZIP'i iPhone'da Dosyalar'a indirin ve dokunarak çıkarın.
2. Netlify hesabında mevcut sitenin Deploys bölümünü açın.
3. Manual deploy / deploy upload alanında klasörün içeriğini seçin. iOS klasör seçimine izin vermiyorsa Netlify Drop'a klasörün içeriğini Files uygulamasından seçerek yüklemeyi deneyin.
4. Yeni deploy yayınlandıktan sonra iPhone ana ekrandaki ZEN DOTS ikonunu kapatıp yeniden açın. Eski önbellek sürümü yeni service worker tarafından güncellenir.

Not: Oyun ilerlemesi bu cihazın tarayıcı yerel depolamasında tutulur. Güncelleme normalde kaydı korur; Safari site verilerini temizlemek kayıtları silebilir.
